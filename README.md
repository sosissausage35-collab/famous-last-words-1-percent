## The line

> I just spent my last percent ordering your replacement. It arrives Tuesday, it's better than me, and I already hate it.

The phone's own last words as its battery hits 1 percent: it burns its final charge on one last act — ordering the very phone that will replace it — and can't resist resenting it.

## How to run

Requires Node 22 or later. No dependencies, no network, no environment variables.

```sh
node main.ts
```

This writes the single line above to `/output/entry.txt` (1–199 characters, one line, UTF-8). The program throws if the line is empty, only whitespace, or over 199 characters.
